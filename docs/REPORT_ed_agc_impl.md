## 2. Последовательность процедуры (UM §7.2.36.2, «Energy Scan»)

Реализована для КАЖДОГО из N отсчётов целиком (`HandleED_AGC_SCAN`, `protocol.c`):

| Шаг UM §7.2.36.2 | Действие в коде |
|---|---|
| (a) настроить канал/параметры | выполняется хостом заранее (`SET_PHY_CONFIG`); команда его не делает |
| (b) `DIS_AM = 0` | `dwt_write16bitoffsetreg(AGC_CTRL_ID, AGC_CTRL1_OFFSET, 0x0000)` |
| (c) включить приёмник (RXENAB) | `dwt_rxenable(DWT_START_RX_IMMEDIATE)` |
| (d) «Wait 32 µs for the AGC to settle» | `ed_agc_delay_us(wait_us)` (дефолт 32; DWT CYCCNT) |
| (e) `DIS_AM = 1` (заморозить результат) | `dwt_write16bitoffsetreg(AGC_CTRL_ID, AGC_CTRL1_OFFSET, AGC_CTRL1_DIS_AM)` |
| (f) прочитать EDG1/EDV2 (AGC_STAT1) | `dwt_read32bitoffsetreg(AGC_CTRL_ID, AGC_STAT1_OFFSET)`, младшие 24 бита |
| (g) выключить приёмник (TRXOFF) | `dwt_forcetrxoff()` |

**Восстановление состояния (требование задания):** после процедуры `DIS_AM = 1` (сбросовое
значение, шаг e), приёмник выключен (шаг g). Регистр `AGC_CTRL1` и состояние приёмника —
как до команды. Каждый отсчёт независим (полный цикл, включая вкл/выкл приёмника).

**Доступ к регистрам** — только через существующие функции драйвера и константы `deca_regs.h`
(`AGC_CTRL_ID`, `AGC_CTRL1_OFFSET`, `AGC_CTRL1_DIS_AM`, `AGC_STAT1_OFFSET`); числовых адресов
и масок в коде нет (младшие 24 бита выделяются сдвигами байт, как в `PUT_U16LE`).

## 3. Пауза 32 мкс — DWT CYCCNT (по решению владельца)

µs-источника в коде не было (`RECON_spi_clockmap`/`RECON_ed_agc`: `deca_sleep`=`HAL_Delay` мс,
CYCCNT не включён, TIM нет). По решению — включаем **DWT CYCCNT под флагом**, с условиями:

- **(а) число тактов НЕ хардкодится:** `cycles = (SystemCoreClock / 1000000u) * wait_us`
  вычисляется в рантайме. `SystemCoreClock` отражает HCLK, задаваемый в `SystemClock_Config`
  (`Core/Src/main.c:159-169`, `HAL_RCC_ClockConfig`; HAL поддерживает `SystemCoreClock`).
  Ожидаемо 72 МГц → 72 такта/мкс, но код от конкретного числа не зависит.
- **Беззнаковая разность** `(uint32_t)(DWT->CYCCNT - start) < cycles` — устойчива к
  переполнению 32-битного счётчика.
- **(б) пауза — параметр команды** `wait_us` (u16); `0` → дефолт **32** (документированное
  UM). Прочие значения — эксперимент с хоста. PARAMS = `N u8 | wait_us u16 LE`.
- Включение `TRCENA` (`CoreDebug->DEMCR`) и `CYCCNT` (`DWT->CTRL`) — через CMSIS, без
  числовых адресов; **целиком под `#ifdef ED_AGC_SCAN`**.
- **Если счётчик не пошёл** (CYCCNT не изменился после включения) — `ed_agc_cyccnt_enable()`
  возвращает 0, обработчик отвечает `STATUS_INTERNAL_ERROR` (сообщаем, не подпираем другим
  механизмом).

## 4. Команда 0x44 (ШАГ 3)

- **Код 0x44** — перепроверено по `protocol.h` (коммит fc893d0): макс. занятый CMD — `0x43`
  (`CMD_CIR_RAW_ARM`), 0x44 свободен.
- **Запрос:** `N u8 | wait_us u16 LE`. `params_len < 3` → `INVALID_PARAM`.
- **Ответ:** `N × 3 байта` — младшие 24 бита `AGC_STAT1` каждого отсчёта «как есть» (LE),
  без распаковки полей/вычислений на плате (распаковку EDG1/EDV2 и статистику делает хост).
- **Предел N:** DATA ≤ 254 (LEN u8: STATUS+DATA ≤ 255) → `N ≤ 254/3 = 84`
  (`ED_AGC_MAX_SAMPLES`). `N=0` или `N>84` → `INVALID_PARAM`.
- **Предусловие (Р3):** `rx_active != 0` → `STATUS_RADIO_BUSY` (код из существующего перечня).
- **Цикл:** процедура шага 2 повторяется для каждого отсчёта целиком (вкл/выкл приёмника);
  отсчёты независимы.
- Устройство: `deca_port_select_device(DW_RX_LISTEN_DEV)` (тот же приёмный модуль, что в
  штатном приёме); при ошибке выбора → `STATUS_RADIO_ERROR`.

Коды STATUS — только из существующего перечня (`STATUS_OK/INVALID_PARAM/RADIO_BUSY/
RADIO_ERROR/INTERNAL_ERROR`), новых не заводил.

## 6. Принятые решения по реализации (обоснование от кода/UM)

1. **Имя поля EDV2 (Р1).** Драйверную `AGC_STAT1_EDG2_MASK` (deca_regs.h:630) не
   переименовывал; в комментарии кода отмечено «EDV2 по UM, в драйвере — EDG2». В отчёте/спеке/
   комментариях — EDV2.
2. **Код команды локальным `#define` в `.c`** (не в enum `protocol.h`): `board_config.h`
   включается в `protocol.c` (стр.21) ПОСЛЕ `protocol.h` (стр.16), поэтому гардить enum
   в `protocol.h` нельзя (макрос ещё не виден). Локальный `#define` под флагом решает это и
   оставляет `protocol.h` без единой правки.
3. **Чтение 24 бит сдвигами байт** (`(uint8_t)v, v>>8, v>>16`) вместо числовой маски —
   выполняет требование «маски числом в код не писать» и даёт «младшие 24 бита как есть».
4. **DIS_AM: запись целого регистра** `0x0000`/`AGC_CTRL1_DIS_AM` — по RECON_ed_agc П2:
   в `AGC_CTRL1` определён только бит0, reserved=0 по сбросу, RMW не требуется.
5. **Устройство — `DW_RX_LISTEN_DEV`** (как в `PROTOCOL_PollRadio`): энергоскан по приёмному
   тракту слушающего модуля.
6. **rx_active → RADIO_BUSY** (Р3): скан только при выключенном непрерывном приёме;
   `PROTOCOL_PollRadio` не изменён ни строкой.

## 7. ВОПРОСЫ К ВАГАНУ

1. **Дополнительные предусловия.** По заданию единственное предусловие — `rx_active==0` (Р3);
   оно и реализовано. НЕ добавлял проверку `dw_dev_state[DW_RX_LISTEN_DEV].initialized` и не
   требую предварительного `INIT`/`SET_PHY_CONFIG` — но для осмысленной энергии канал должен

   `.initialized` (вернуть ошибку, если модуль не инициализирован)?

3. **Значение η (eta)** — по UM Table 27 для канала 2 η=1.3335 (зафиксировано в RECON_ed_agc
   как факт). В код не введено (относительный контраст). Подтверждение, что так и надо.
